# Zapret GUI

Лаконичная тёмная GUI-оболочка для управления [zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube) (DPI-обход) и [tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy) (ускорение Telegram Desktop).

## Возможности

- **Первый запуск** — автоматически скачивает оба сервиса с GitHub Releases
- **zapret**: выбор стратегии (`general.bat`, `ALT`, `FAKE TLS`…), запуск/остановка,
  установка **службы Windows** (автозапуск до входа в систему), Game Filter (off/TCP/UDP/TCP+UDP),
  IPSet (none/any/список + обновление), обновление дистрибутива с сохранением пользовательских списков
- **свои домены** — «маскировать / исключить / исключить IP» чипами; кнопка «Проверить и добавить»
  сама проверяет сайт с обходом и без, выбирает режим и перезапускает zapret (см. 0.2.5.0)
- **автолечение доменов** (Windows, 0.2.6.0) — пассивно следит за TLS-соединениями браузера
  (сниффер WinDivert, трафик не задерживается и не меняется), ловит сбои (RST/нет ответа) и сам
  прогоняет «с обходом/без», записывая домен в нужный список; по умолчанию безопасный режим
  «только журнал». Трафик не сохраняется — в журнал попадают только домены со сбоями
- **tg-ws-proxy**: запуск в портативном режиме, ссылка `tg://proxy` (копировать / открыть в Telegram),
  автозапуск, обновление; наследует конфиг и секрет от ранее установленной версии
- **Диагностика** — перенос проверок из `service.bat`: BFE, TCP timestamps, системный прокси,
  конфликтующие службы (Killer, Intel Connectivity, Check Point, SmartByte, Adguard, VPN),
  Secure DNS, hosts, WinDivert
- **Трей** — закрывается в трей, единый журнал процессов
- **Терминальный функционал сохранён** — кнопки открывают оригинальные `service.bat` и bat стратегии
## Сборка

Требуется: Go 1.22+, Node.js 18+, WebView2 (встроён в Win10/11).

```bash
wails build          # build/bin/ZapretGui.exe (~12 МБ)
```

Разработка: `wails dev` (из elevated-терминала), флаг `-no-elevate` отключает запрос UAC.

## Замечания

- **Версионность платформ независимая**: Windows `0.2.x`, macOS `0.2.x-mac.N` —
  детали в [docs/VERSIONING.md](docs/VERSIONING.md). Не путать!
- Приложение запрашивает права администратора: WinDivert (драйвер zapret) их требует
- Антивирусы могут ругаться на WinDivert: **при первом запуске GUI сам добавляет
  свои каталоги в исключения Windows Defender** (кнопка «исключение в Defender»
  в настройках — для повторной установки). Если сам ZapretGui.exe уже попал
  в карантин до запуска — восстановите его в окне Defender («Разрешить»);
  дальше приложение всё сделает само. Радикальное лечение — подпись кода.
- Для работы YouTube в браузере должен быть включён Secure DNS (Chrome/Firefox/Win11)
- Данные: `%LOCALAPPDATA%\ZapretGui` (или папка `Zapret_gui_data` рядом с exe — портативный режим)

## История версий (Windows)

- **0.2.8.0** — **детект QUIC (HTTP/3)**: наблюдение теперь покрывает и UDP/443.
  QUIC Initial расшифровывается пассивно (ключи выводятся из DCID, версии v1/v2),
  из CRYPTO-фрейма собирается ClientHello и достаётся SNI; если сервер не ответил
  за 5 с — это событие, как и для TCP. Имя процесса для QUIC берётся из UDP-таблицы
  Windows (`GetExtendedUdpTable`), в журнале: «домен · chrome.exe: нет ответа (QUIC)».
  Слепые зоны: 0-RTT/ECH и нестандартные draft-версии — такие пакеты пропускаются
  без ложных событий
- **0.2.7.0** — **автопауза zapret при VPN** и **журнал по приложениям**:
  пока интернет идёт через VPN (маршрут по умолчанию уходит в туннельный адаптер —
  WireGuard/OpenVPN/Clash/Tailscale-exit и т.п.), zapret ставится на паузу, а после
  выключения VPN возвращается; автолечение на это время тоже замирает. Tailscale/Clash
  в режиме mesh (туннель поднят, но интернет идёт напрямую) паузой не считается — в журнале
  об этом отдельная строка. Переключатель «пауза при VPN» — в карточке zapret.
  Второе: события автолечения подписываются процессом-владельцем соединения
  (`telemetry.anytype.io · anytype.exe: нет ответа`) — по TCP-таблице Windows (PID),
  чтобы видеть, чьи домены ломаются, а не только какие
- **0.2.6.2** — статус автолечения в UI теперь живой и честный: обновляется каждые 2 с
  (раньше рисовался один раз при загрузке окна и мог навсегда показать «наблюдение не запущено»,
  хотя оно работало); причина, по которой наблюдение не поднялось, выводится текстом, а не
  ложным «нужны права администратора»; рядом появилась кнопка «перезапустить наблюдение»
  (без перезапуска приложения). Плюс режим «только журнал» инициализируется при старте
  приложения, поэтому галочки в UI сразу соответствуют конфигу
- **0.2.6.1** — исправление запуска zapret после обновления дистрибутива: фоновый
  сниффер больше не держит WinDivert-драйвер во время старта/остановки службы и обновления
  (из-за этого драйвер застревал в STOP_PENDING, winws падал с кодом 433, а в UI было
  «служба запущена» без зелёной лампы). Запуск службы теперь проверяется по факту RUNNING,
  ошибка с кодом выхода пишется в журнал и показывается пользователю; переходы состояния
  zapret пишутся в журнал; после обновления WinDivert.dll перезагружается
- **0.2.6.0** — **автолечение доменов**: фоновое наблюдение за TLS-соединениями браузера
  (пассивный сниффер WinDivert, `internal/netwatch`: SNI из ClientHello, детектор RST/таймаута,
  политика «2 сбоя за 10 минут, пауза по домену 6 ч, ≤3 действий в час») и автоматический прогон
  «с обходом/без» с записью списка; по умолчанию — безопасный режим «только журнал», лечение
  включается галочкой в блоке «свои домены»
- **0.2.5.0** — «свои домены»: кнопка **«Проверить и добавить»** — автопроверка сайта
  с обходом и без, автоматический выбор режима (маскировать / исключить / ничего
  не делать), автоприменение списка и безусловный перезапуск zapret; если сайт после
  применения так и не открылся — сообщение «автолечение не помогло». При смене режима
  домен убирается из противоположного списка, чтобы не было противоречий. «Недоступен»
  подтверждается вторым замером (одиночный замер нестабилен), а HTTP 4xx/5xx (бот-защита,
  ошибка сервера) считаются «сайт живой» — здоровые домены не лечатся. IP/CIDR —
  по-прежнему вручную (проверка доступности по IP не поддерживается)
- **0.2.4.0** — редизайн: вкладки «Обход·zapret»/«Telegram·tg-ws», свои домены — управляемые чипы вместо блокнота (заглушки скрыты, полный сброс безопасен), кнопка «Перезапустить» полноразмерная; тест стратегий — внутри вкладки zapret
- **0.2.3.0** — «свои домены»: редактор пользовательских списков в GUI
  (маскировать / исключить / исключить IP-CIDR — с валидацией строк и
  заглушкой вместо пустого списка) с опцией «перезапустить после
  сохранения»; кнопка «⟳ перезапуск» у стратегии (служба или процесс —
  как работало). Мотивация: SNI-душимые сайты (пример: johnsad.ventures)
  лечатся добавлением в list-general-user.txt, а ломаемые zapret CDN —
  в list-exclude-user.txt (пример: zendesk.com, cloudfront.net)
- **0.2.2.3** — починен автозапуск (инцидент 25.08 «65 минут тишины»):
  watchdog-перезапуск раньше делался слепой цепочкой `timeout &
  schtasks /Run` без ретраев и логов — /Run упирался в IgnoreNew
  (планировщик ещё считал только что вышедший экземпляр живым) и
  тихо отказывал (0x800710E0). Теперь рестарт — супервизором
  `--watchdog-respawn`: ждёт освобождения мьютекса, до 3 попыток,
  каждый шаг в log.txt. Задача планировщика: убран лимит времени
  72ч (ExecutionTimeLimit → PT0S), регистрация через
  Register-ScheduledTask (schtasks /XML на этой машине не работает);
  флаги батарей сняты (безвредно на десктопе)
- **0.2.2.2** — автолечение «мёртвого значка в трее» после загрузки ПК (watchdog:
  перезапуск через задачу автозапуска, если трей не поднялся за 30с);
  таймаут порта tg-ws 6с→10с (медленный старт диска/антивируса);
  два процесса TgWsProxy в диспетчере задач — норма (PyInstaller parent+child)
- **0.2.2** — автоисключения Windows Defender; первый запуск не стартует стратегию
  сам (после выбора — автозапуск); ЛКМ по иконке трея — показать/скрыть окно
- **0.2.0–0.2.1** — полный тест стратегий, диагностика, установка zapret-службы

## Структура

```
internal/
  config/   — конфиг приложения, портативный режим
  release/  — GitHub Releases: инфо, скачивание с прогрессом, распаковка zip
  zapret/   — парсер стратегий, процесс/служба, Game Filter/IPSet, обновление
  tgws/     — запуск --portable, конфиг/секрет, tg:// ссылка, автозапуск
  diag/     — диагностика (перенос из service.bat)
  winutil/  — admin/UAC, единственный инстанс, HKCU Run, ShellExecute
frontend/   — vanilla TypeScript + Vite, тёмный минимализм без фреймворков
```
